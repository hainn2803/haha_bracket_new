Quick update on the OpenAI sparse-circuit experiments. Ablating the quote-type site `0.mlp.resid_delta:460` reduced accuracy from 100% to 54%, while ablating the bracket binary-readout site `4.attn.resid_delta:1079` reduced accuracy from 100% to 59%. Rerunning PLOT over all remaining localized sites did not find a valid replacement in either task.

More interestingly, staged PLOT recovered a graded bracket-depth variable. It first selected `4.attn.act_in:1249`, which decoded active depth on fresh heldout data with Pearson 0.997 and R2 0.994. A second upstream search selected `2.attn.resid_delta:1249 + 3.attn.resid_delta:1249`. Patching depth 2 to 4 changed the internal depth state while preserving the `]]` output; patching depth 1 to 3 changed both. All heldout certification tests passed at 100%.

This supports `X -> D -> R -> Y`, where `D` is active depth and `R = 1[D >= 2]`. The sites closely match OpenAI's manual circuit: layer 2 writes depth to channel 1249, layer 3 amplifies it, and layer 4 thresholds it into channel 1079. The main caveat is that the output task remains binary and we have not yet tested long-context dilution. I packaged the code and results in `openai_sparse_ablation_progressive_student_repro_20260715.zip`.
